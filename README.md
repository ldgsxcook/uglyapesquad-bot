# Ugly Ape Squad Bot v2

A Web3 Discord bot for the Ugly Ape Squad ecosystem.

## Features
- Solana holder verification
- Token-gated Discord roles
- Mint tracking
- Marketplace alerts
- XP and mutation system
- AI image prompt generation
- Dashboard starter

## Stack
- Node.js
- discord.js
- Helius API
- Railway
- Next.js dashboard

## Commands
- /ape
- /mutate
- /verify
- /holder
- /mint-status
- /floor
- /leaderboard

## Deploy
1. Add environment variables
2. Run npm install
3. Run npm run deploy-commands
4. Run npm start
